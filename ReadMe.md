# Oblivionis · 忘却时刻

一个 Windows 桌面关机/重启确认对话框，名称取自 Ave Mujica 歌曲《Oblivionis》。双击运行即弹出深色确认框，可立即关机或重启。

## 功能

| 操作 | 行为 |
|---|---|
| 点击「再等等」或按 Esc | 关闭对话框，不关机 |
| 点击「重返舞会」 | 立即重启电脑（`shutdown /r /t 0`），无缓冲、无撤销 |
| 点击「忘却」或按 Enter | 立即关机（`shutdown /s /t 0`），无缓冲、无撤销 |
| 点击「忘却」右侧 ▼ | 展开「晚点睡」菜单：可选 15/30 分钟、1/2 小时后定时关机；**重选时长会直接覆盖旧计划**（无需先取消）；已定时再点 ▼ 可取消 |
| 点击左上角月亮 | 窗口最小化到任务栏（可点回恢复，不藏托盘） |
| 点击右上角祥子贴纸 | 播放语音彩蛋 |

- 默认焦点落在「再等等」，防止误触回车直接关机
- 已定时的状态下，「忘却」「重返舞会」保持锁定（防误触减速带），先在 ▼ 菜单取消即可解锁
- 一条关机/重启命令投出后，进程存活期内其他按钮点击会被忽略，避免命令互相覆盖
- 定时关机后状态栏实时显示倒计时（超过 1 小时自动切换时:分:秒格式）
- 系统命令执行失败时状态栏会明确提示「执行失败」，不会出现假"进行中"
- 「晚点睡」定时关机由系统执行，关掉对话框不影响计时；取消用菜单里的「取消已定的关机」
- 无边框、圆角、深色渐变、置顶居中、可拖标题区移动；任务栏与 Alt-Tab 显示程序标题和图标
- 布局随系统 DPI 缩放（PerMonitorV2 + Dpi 缩放），高分屏不再错位

## 快捷键

| 按键 | 作用 |
|---|---|
| Enter | 立即关机 |
| Esc | 关闭对话框 |
| Tab | 切换焦点（再等等 → 重返舞会 → 忘却） |

## 文件结构

```
Oblivionis.exe     构建产物（交付物，本地拷贝使用，不进仓库）
Program.cs         全部源码（单文件，刻意保持小而美）
Oblivionis.csproj  工程文件（含图标与嵌入资源声明）
build.sh           一键构建并同步到桌面
assets/app.ico     exe 图标
assets/sakiko.png  Q版祥子贴纸（透明 PNG）
assets/cn019.wav   祥子语音彩蛋
ReadMe.md          本说明
```

## 本机构建（Windows + Git Bash）

PowerShell 缺环境变量，必须经 Git Bash 构建：

```bash
cd "/d/桌面/oblivionis" && ./build.sh
```

（等价于 `dotnet publish -c Release` 后把产物拷到 `/d/桌面/Oblivionis.exe`。）

## 注意事项

- 框架依赖单文件发布，运行需本机已装 .NET 8 桌面运行时
- 更换贴纸/语音：替换 `assets/` 下同名文件后重新编译即可（勿改 LogicalName）
- 关机/重启均无撤销，请先保存工作
